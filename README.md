# أثر

لوحة عربية لإدارة أعمال القسم. المشروع مستقل ويعمل محليًا دون خدمات تشغيل أو مصادقة خاصة بمنصة خارجية.

## مكوّنات المستودع

- `client/`: واجهة الويب المتجاوبة وتطبيق PWA.
- `server/`: الخادم، المصادقة، واجهات tRPC، وخادم MCP.
- `shared/`: الأنواع وقواعد العمل المشتركة.
- `drizzle/`: مخطط قاعدة البيانات وترحيلاتها المتسلسلة.
- `android/` و`ios/`: حاويتَا تطبيق الجوال المبنيتان بـ Capacitor.
- `deploy/` وملفات Docker: إعدادات تشغيل بيئة الإنتاج على VPS.
- `assets/`: المصدر الأصلي لأيقونة التطبيق وشاشة البدء.

لا تُرفع ملفات `.env` أو مفاتيح التوقيع أو مخرجات البناء. راجع ملفات
`.env.example` و`.env.production.example` لمعرفة القيم المطلوبة دون أسرار.

## التشغيل محليًا

المتطلبات: Node.js 20 أو أحدث، وpnpm، وMySQL 8. يمكن تشغيل MySQL المرفق عبر Docker:

```bash
cp .env.example .env
docker compose up -d db
pnpm install
pnpm db:push
pnpm dev
```

افتح `http://localhost:3000` وسجّل الدخول بحساب تمت دعوته. الحساب الذي يطابق `ADMIN_EMAIL` يحصل على صلاحية مدير المنصة، ومن لوحة الإدارة يستطيع دعوة مدراء الأقسام. ينشئ كل مدير لوحته المستقلة ثم يدعو أعضاء فريقه.

## الخلاصات البحثية

يحدد مدير كل لوحة موضوعات البحث وكلماتها المفتاحية من تبويب
`الخلاصات البحثية`، وتظهر النتائج لجميع أعضاء اللوحة. يجلب الخادم أحدث
الأبحاث من arXiv تلقائيًا كل ست ساعات، ويمكن للمدير تشغيل التحديث يدويًا،
كما يستطيع أعضاء الفريق ربط أي نتيجة بمشروع داخل اللوحة. لا تتطلب هذه
الميزة مفتاح ذكاء اصطناعي أو API مدفوعًا، لكنها تتطلب السماح للخادم باتصال
HTTPS صادر إلى `export.arxiv.org`.

## متغيرات البيئة

- `DATABASE_URL`: رابط اتصال MySQL.
- `JWT_SECRET`: مفتاح طويل وعشوائي لتوقيع جلسات الدخول.
- `ADMIN_EMAIL`: البريد الذي يحصل على صلاحية مدير المنصة.
- `PUBLIC_URL`: رابط أثر العام، مثل `https://athr.aidept.io`.
- `PORT`: منفذ الخادم، والافتراضي `3000`.

## الربط مع ChatGPT وClaude

يوفر أثر خادم MCP بعيدًا على المسار `/mcp`، ويستخدم OAuth لتوصيل كل مستخدم
بحسابه الشخصي دون مشاركة كلمة مروره أو إنشاء مفتاح API. رابط الربط في بيئة
الإنتاج هو:

```text
https://athr.aidept.io/mcp
```

بعد إضافة الرابط في عميل يدعم MCP، ينقل أثر المستخدم إلى شاشة الدخول ثم يطلب
موافقته على الربط. جميع الأدوات تمر بصلاحيات أثر نفسها: المشاهد للقراءة فقط،
والعضو يعمل داخل المشاريع المتاحة له، ومدير اللوحة يستطيع أيضًا إدارة الأعضاء
والأهداف. يمكن للمستخدم مراجعة الاتصالات وإلغاؤها من صفحة الإعدادات.

يدعم الربط قراءة وإنشاء وتعديل وحذف المشاريع والمهام والدروس المستفادة والأهداف
والتقويم والاهتمامات البحثية، إضافة إلى التعليقات وطلبات الدعم ودعوات الفريق.
تكلفة المحادثة تقع على حساب المستخدم في ChatGPT أو Claude؛ خادم أثر لا يستدعي
نموذجًا لغويًا ولا يحتاج إلى مفتاح OpenAI أو Anthropic.

## التحقق والإنتاج

```bash
pnpm check

pnpm build
pnpm start
```

قبل النشر، اضبط المتغيرات السابقة في بيئة الاستضافة واستخدم اتصال MySQL دائمًا. تسجيل الدخول المحلي مناسب لتشغيل المنصة داخليًا؛ ويمكن لاحقًا استبداله بمزود OIDC قياسي دون تغيير بقية التطبيق.

## النشر على Hostinger VPS

المشروع مجهز للنشر باستخدام Docker Compose. انسخ
`.env.production.example` إلى `.env.production` وعدّل النطاق وكلمات المرور
والأسرار، ثم شغّل:

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml up -d --build
```

يجب أن يشير سجل DNS من نوع `A` للنطاق إلى عنوان VPS. تقوم خدمة Caddy
بتمرير الطلبات إلى التطبيق وإصدار شهادة HTTPS تلقائيًا، بينما تبقى MySQL
داخل شبكة Docker ولا يُفتح منفذها للإنترنت.

للتحقق من التشغيل:

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml ps
docker compose --env-file .env.production -f docker-compose.prod.yml logs --tail=100 app caddy
```

## تطبيق الويب والجوال

الموقع نفسه تطبيق ويب تقدمي (PWA)، ويمكن تثبيته من المتصفح على الجوال
والكمبيوتر. كما توجد مشاريع iOS وAndroid أصلية مبنية باستخدام Capacitor،
وتستخدم نفس نسخة الإنتاج على `https://athr.aidept.io`؛ لذلك تظهر تحديثات
المنصة داخل التطبيق مباشرة وتبقى الحسابات والبيانات موحدة.

لمزامنة تطبيقَي الجوال بعد تعديل الإعدادات أو الإضافات الأصلية:

```bash
pnpm mobile:sync
```

لفتح مشروع iOS (يتطلب Xcode على macOS):

```bash
pnpm mobile:ios
```

ولفتح مشروع Android (يتطلب Android Studio وJDK):

```bash
pnpm mobile:android
```

هوية التطبيق هي `io.aidept.athr`. ملفات المصدر الأصلية موجودة في `ios/`
و`android/`، وأصول الأيقونة وشاشة البدء في `assets/`.
